AutoCharge Maroc — WhatsApp-only static sample

Deploy the contents of this folder as a static website. On Vercel choose Framework Preset: Other. No build command, environment variables, server, database, or order API are needed. The entry page is index.html.

Orders: A customer fills the form, then opens a prefilled chat to +212 6 08 73 13 53. The customer must press Send inside WhatsApp. This sample does not record orders in a dashboard or confirm delivery automatically. Change the WHATSAPP_ORDER_NUMBER value in assets/site.js if your business number changes.

Product images hosted on marocor.com and Google Fonts require internet access.
